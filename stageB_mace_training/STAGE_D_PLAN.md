# Stage D plan: N impacts with a DFT-trained MACE

Status: not started. This is a plan, not results. Numbers marked *(measured)* come from this project's Stage B/C runs; everything else is an estimate.

## What Stage D compares

The MD repo has **no N bombardment**: its README states that the available ReaxFF set (`ffield.reax.CHN`, a nitramine parametrisation) does not describe graphene
well (vacancy formation energy 3.6 eV against 7.65 eV with AIREBO) and plans a MACE potential trained on DFT C-N data instead. `CH.airebo` has no nitrogen.
So there is **no usable classical reference for N** here. Stage D is therefore not a paired comparison like Stage C: it is (i) DFT data for C-N, (ii) a fine-tuned MACE,
(iii) its validation against DFT (static scans, doped defects, impact frames), and only then (iv) MACE N impacts, with no classical counterpart to compare against
(the ReaxFF set could be run as a labelled-as-poor baseline if wanted).
Why N is harder than Ar: N is chemically active. It can bond (adatom, substitution, pyridinic/pyrrolic sites at a vacancy), the isolated atom is a quartet (3 muB), and
doped vacancies are magnetic and hard for SCF (the same difficulty met with the Ar frames).

## What MACE needs that it does not have

The current model (omat-0 fine-tuned on C data plus Ar scans) has no N-C labels. It needs N data in the same recipe (GPAW PBE, 450 eV, k-density 5, 4x4 sheet = 32 +/- 2 atoms).

| block | content | rows | purpose |
|---|---|---|---|
| D1 | isolated N atom (quartet) and N2 molecule in the sheet cell | 2 | reference energies (E0, formation energies) |
| D2 | static N-C approach scans: top / bridge / hollow, N-C 1.15-4.5 A (recipe minimum C-N is 1.1 A), flat sheet, plus rattled copies; `scans.py` (see below) | 46 | long-range and repulsive wall, like the Ar scans |
| D3 | doped and defective sheets: graphitic N, N adatom (bridge, top), pyridinic N at V1 (1 N, 2 N), pyrrolic, V2 with 4 N; relaxed bases + rattled/strained copies (the existing `configs.py` machinery) | about 40 | bonded states: the bonding the model must learn |
| D4 | impact frames (like `framescan.py`): N on 4x4 at top / bridge / hollow, 30-70 eV, dynamics by MACE (ReaxFF optional as rough generator), DFT on frames with C-N >= 1.1 A | about 24 | arbiter test on dynamics-relevant geometries |

Total about 110 DFT structures (46 scans + about 40 doped sheets + about 24 frames). Measured cost of a 32-atom structure is 8-10 min on 5 MPI ranks for flat/mildly distorted sheets and up to about 30 min for strongly distorted ones *(measured, push scan)*, so about 15-20 h of DFT in total, spread over several nights (the flow is resumable).

## Things that must be solved first (not yet done)

1. **Spin of the isolated N atom: DONE (tested with EMT only, not with GPAW).** `recipe.compute` keeps initial moments a row carries and uses the recipe 0.3 muB only when all moments are zero (all existing rows are unchanged). `scans.py --proj-magmom 3.0` writes N with 3 muB and the sheet atoms with 0.3 muB. The final moment of the isolated N row must come out near 3 muB: check it before using the row. For scan rows, the spin state at intermediate N-C distances can be ambiguous: `spincheck.py` re-runs from other starting moments.
2. **SCF robustness.** N-doped vacancies are magnetic and can be hard to converge; the existing `MLIP_MIXER` / `MLIP_EIGENSOLVER` / `MLIP_MAXITER` switches and the failed.jsonl bookkeeping already handle failures, but expect a few rows to fail.
3. **Scan script: DONE (tested with EMT only).** `scans.py --proj N --family n --proj-magmom 3.0 --dir data/nscan --dist 1.15 1.3 1.5 1.65 1.8 1.95 2.1 2.3 2.6 3.0 3.5 4.5 --rattle-dist 1.3 1.8 2.6` writes 46 rows (1 isolated N + 36 flat scans + 9 rattled), families `n-atom` / `n-scan`; Ar defaults are unchanged. A frozen-sheet scan is not a relaxed adsorption energy: at 1.15-1.5 A the N would bond and pull the sheet, so these rows are points on the surface, not minima.
4. **Dynamics for D4 frames.** With no classical N potential, the frames must come from MACE dynamics (ASE, as in Stage C) or from ReaxFF if used as a rough generator; the frame set is then not independent of the model it tests, so DFT-labelled frames are the only honest check.
5. **Training and held-out sets.** D4 frames stay a test set (as the Ar frames do); D1-D3 are training data. Keep one doped family held out (`finetune.py --holdout-family`) for an honest bonded-state test.

## Order of work and acceptance tests

1. D1 + D3 first (defect energies are the cheap and decisive test): fine-tune, then compare N-doped defect formation energies, MACE vs DFT (5x5 cells, like the Stage B acceptance run).
2. D2 (wall and tail), then fine-tune with `--foundation_model_elements True` (needed so the model keeps N and Ar; found in Stage B).
3. D4 frames: DFT vs MACE on frames generated by MACE (and ReaxFF if used), as in `framescan.py`.
4. Only then MACE N impacts (8x8 sheet, same protocol as Stage C), reported without a classical counterpart.

## Risks (stated, not hidden)

* MACE on CPU costs about 5-6 ms/atom/step *(measured)*; an 8x8 sheet impact costs about 50 min.
* DFT cannot label the closest-contact regime (PAW cores overlap) for N either; the same limit as for Ar applies and must be stated.
* A small training set (about 100 rows) may leave the model weak on configurations far from the data; the held-out family is how that would show.
